# Python Logic & Control Flow: Learning Plan

How it works: watch the course section, do the module's exercise notebook, then ask Claude to grade it.
Pass mark for each module: 8/10, including at least 2 of the 3 Level 3 exercises. Move on only after you pass.

| # | Module | Covers | Status |
|---|--------|--------|--------|
| 1 | Boolean values & functions | `True`/`False`, `bool()`, truthy/falsy, `isinstance()`, `is_integer()`, string `is...()` methods, `any()`/`all()` | ✅ Passed 9.5/10 (2026-11-16) |
| 2 | Comparison operators | `==`, `!=`, `<`, `>`, `<=`, `>=`, chained comparisons, comparing strings, float precision | Not started |
| 3 | Logical operators | `and`, `or`, `not`, precedence, short-circuiting, `or` for default values | Not started |
| 4 | Membership operators | `in` / `not in` with strings, lists, tuples, sets and dict keys | Not started |
| 5 | Identity operators | `is` / `is not`, `is None`, `is` vs `==`, mutable vs immutable objects | Not started |
| 6 | Conditional statements | `if`/`elif`/`else`, nesting, conditional expressions, `match` | Not started |
| 7 | Loops | `for`, `while`, `range`, `enumerate`, `break`/`continue`, loop `else` | Not started |
| 8 | Capstone | Mini data-validation project that uses every module | Not started |
